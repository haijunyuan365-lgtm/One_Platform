## 一、交付目标

本计划用于指导公司一体化平台从现有 Vue 前端工程逐步交付到可演示、可验收、可联调的完整版本。第一阶段以 `admin` 管理后台和 `website` 前台门户为主要交付对象，保持 Mock 模式开启，优先完成页面、路由、类型、API Mock、交互与构建验证。

## 二、范围拆分

| 阶段 | 名称 | 目标 | 完成标准 |
|---|---|---|---|
| Phase 0 | 基础梳理 | 确认文档、工程、Mock、路由和已有页面状态 | 交付计划建立，推荐第一步明确 |
| Phase 1 | 前端原型 | 完成全部页面与 Mock 业务闭环 | 页面可登录访问，功能可演示，构建通过 |
| Phase 2 | 接口联调 | 将 Mock API 平滑替换为真实接口 | 接口字段、错误处理、权限结果符合 SRS |
| Phase 3 | 测试验收 | 完成功能、权限、边界、安全和兼容验收 | 测试用例通过，问题闭环 |
| Phase 4 | 上线准备 | 完成部署配置、初始化数据和操作手册 | 可部署、可回滚、可交接 |

## 五、每个页面工作包的交付清单

每个工作包完成时必须包含：页面入口、路由模块、菜单国际化 key、类型定义、API 函数、固定 Mock 数据、列表筛选、分页或树表、弹窗表单、启停或删除等核心操作、空状态和错误提示。管理后台页面遵循 `admin/README-DEV.md`：页面文本直接中文，菜单名称使用 `zh.json` 与 `en.json`，表格使用 Element Plus `ElTable`，页面完成后运行 `pnpm build` 验证。

## 六、验收关注点

| 模块 | 核心验收点 |
|---|---|
| 系统管理 | 用户、部门、角色能支撑项目授权；用户重置密码需补齐 |
| 项目管理 | 项目卡片、地址、凭据、二维码、说明可以独立维护并关联同一项目 |
| 状态检测 | 支持自动检测配置、立即检测、人工状态覆盖和检测记录查看 |
| 权限与审计 | 项目可见权限与密码查看/复制权限分离；敏感操作可查询和导出 |
| 前台门户 | 只展示授权项目；详情弹窗按权限展示地址、密码、二维码和说明 |
